# Check Even or Odd

## Description

This Python program checks whether a given integer is even or odd using the modulus operator.

The program also identifies whether the entered number is positive, negative, or zero.

## Concepts Used

* Variables
* User Input
* Type Conversion
* Modulus Operator
* Conditional Statements
* Functions
* Return Values
* Exception Handling

## Technologies

* Python 3

## How to Run

```bash
python even_or_odd.py
```

```text

================================

Result : Even
```
